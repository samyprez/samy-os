# Samy OS

MVP inicial del centro de operaciones de Samy Prez.

## Incluido

- Dashboard ejecutivo responsive
- Navegación con Lucide Icons
- Tarjetas de clientes, pendientes, agenda e ingresos
- Asistente ejecutivo visual
- Lista inicial de tareas y enfoque recomendado

## Ejecutar localmente

```bash
npm install
npm run dev
```

Luego abre `http://localhost:3000`.
